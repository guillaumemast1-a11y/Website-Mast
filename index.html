How it works

Three steps to zero manual work

Built for accounting firms managing multiple clients. Connect once, configure rules, let it run.

01

Connect your client

Link the client's Mollie account and Exact Online division. Takes 2 minutes. We handle OAuth and token refresh automatically — nothing to maintain.

02

Set booking rules

When a new payment type arrives, Rekoncile asks you to map it to GL accounts. Set it once — all future payments of the same type follow the same rule.

03

Everything books itself

Payments, refunds, and chargebacks are posted to Exact Online every 5 minutes. No manual exports, no copy-paste, no errors.

Features

Built for accounting firms

Everything you need to handle PSP reconciliation at scale, across all your clients.

Multi-client

All clients in one place

Each client gets their own Mollie and Exact Online connection. Switch between accounts instantly. See the booking status of every administration at a glance.

Rule engine

Flexible booking rules per PSP

Map any combination of PSP × transaction type to your GL accounts. Paid, refunded, partially refunded, chargeback — each gets its own rule.

Exact Online

Native API integration

We post directly to Exact's General Journal API using the correct dagboek and grootboekrekeningen. No middleware, no file imports, no CAMT files.

Reliability

Automatic retries & error tracking

Failed bookings retry automatically. Every booking is logged with its Exact entry ID. You always know what was booked, when, and why it succeeded or failed.

Pricing

Simple pricing, per client

One flat monthly fee based on how many clients you manage. No per-transaction costs, no surprises.
